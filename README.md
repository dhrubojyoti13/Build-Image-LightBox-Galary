# 🖼️ Image Lightbox Gallery Using HTML, CSS & JavaScript

A simple, responsive, and interactive **Image Lightbox Gallery** built using HTML, CSS, and JavaScript. This project allows users to browse a collection of images and view them in a larger popup overlay without leaving the webpage.

When users click on an image, it opens in a lightbox with navigation controls for browsing through the gallery.

## ✨ Features

- 🖼️ **Image Gallery:** Displays multiple images in an organized grid layout.
- 🔍 **Lightbox Effect:** Opens selected images in a larger popup view.
- ⬅️ **Previous Button:** Navigate to the previous image.
- ➡️ **Next Button:** Navigate to the next image.
- ❌ **Close Button:** Close the lightbox popup.
- 🖱️ **Interactive UI:** Smooth image interactions.
- 📱 **Responsive Design:** Adapts to different screen sizes.
- 🎨 **Clean Interface:** Simple and attractive design.

## 🛠️ Technologies Used

- **HTML5** – Structure of the gallery.
- **CSS3** – Styling, layout, transitions, and animations.
- **JavaScript** – Lightbox functionality and image navigation.

- Open the project folder in VS Code.
- Open `main.html` in your browser.

No additional dependencies or installation are required.






## ⚙️ How It Works

1. HTML creates the image gallery structure.
2. CSS arranges images in a responsive grid.
3. JavaScript handles image click events.
4. The selected image opens inside a lightbox overlay.
5. Previous and Next buttons allow users to navigate between images.
6. The Close button hides the lightbox and returns to the gallery.
